# HepsiEmlak Veri Çekme Botu

HepsiEmlak'taki ilanları gezip filtreleyen ve Firebase Realtime Database'e kaydeden masaüstü bot (C#, .NET 8, Windows Forms, Selenium). RE/MAX için geliştirdiğim Scout Bot sisteminin parçasıdır; toplanan ilanlar WhatsApp botu tarafından işlenir.

**Kurulum:** `FIREBASE_DATABASE_URL` ortam değişkenine kendi Firebase veritabanı adresinizi yazın, ardından `dotnet run`.
Toplanan ilan verileri ve tarayıcı profili depoya eklenmez.
